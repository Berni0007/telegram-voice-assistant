# Telegram Voice Assistant RU

Приватный Telegram-бот с голосовым вводом, NVIDIA AI и постоянной памятью.

## Что умеет

- принимает текст и голосовые сообщения;
- распознаёт русскую речь через NVIDIA Parakeet RNNT Multilingual ASR;
- отвечает через `nvidia/nemotron-3.5-lightning-30b-a3b`;
- озвучивает ответы через NVIDIA Chatterbox Multilingual `ru-RU`;
- хранит историю и долгосрочную память в SQLite;
- сохраняет память после перезапуска;
- использует структурированную память: факты, проекты, решения, предпочтения и открытые темы;
- ищет нужные старые воспоминания по смыслу через embeddings `baai/bge-m3` на NVIDIA API;
- автоматически отслеживает незавершённые темы и закрывает завершённые;
- Personality Engine адаптирует длину, тон и характер ответа под текущую ситуацию и изученный стиль пользователя;
- память обновляется в фоне и не должна задерживать основной ответ;
- длинные TTS-ответы автоматически разбиваются на безопасные фрагменты;
- текст ответа в Telegram не удаляется, даже если TTS/сеть позже дали ошибку.

## Команды

- `/start` — информация о боте
- `/mode` — режим ответа
- `/voice` — стиль русского голоса
- `/new` — новый диалог с сохранением важных фактов и открытых тем
- `/memory` — состояние памяти, открытые темы и изученный стиль
- `/forget` — полностью очистить память пользователя
- `/voices` — техническая информация о TTS
- `/diag` — безопасная диагностика хоста/NVIDIA API

## Память v5.2

SQLite хранит обычную историю сообщений и отдельные структурированные элементы памяти:

- `preference` — устойчивые предпочтения;
- `style` — предпочтительный стиль ответов;
- `fact` — важные явно сообщённые факты;
- `project` — длительные проекты и задачи;
- `decision` — принятые решения;
- `open_topic` — незавершённые темы.

Для каждого нового вопроса бот ищет релевантные воспоминания по смыслу и добавляет только их в контекст модели. Открытые темы и устойчивые стилевые предпочтения учитываются отдельно.

Извлечение новых воспоминаний работает в фоне каждые несколько пользовательских реплик. Секреты, токены и ключи в память сохранять запрещено системным промптом.

## Структура

`bot.py` — точка входа. Код хранится в `src/part_*.py` и загружается в одном общем namespace в исходном порядке.

## Локальный запуск

Требуется Python 3.11+.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните в `.env`:

```env
TELEGRAM_BOT_TOKEN=...
NVIDIA_API_KEY=...
```

Запуск:

```powershell
.\.venv\Scripts\python.exe .\bot.py
```

## Docker / Bothost

Сборка:

```bash
docker build -t telegram-voice-assistant .
```

На Bothost база должна находиться в постоянной директории:

```env
BOT_MEMORY_DB=/app/data/bot_memory.db
```

На Linux локальное воспроизведение через Windows `winsound` автоматически отключается. Голосовое сообщение в Telegram продолжает отправляться.

## Безопасность

В репозиторий **не должны попадать**:

- `.env`;
- Telegram Bot Token;
- NVIDIA API Key;
- `bot_memory.db`;
- голосовые/временные аудиофайлы;
- логи.

Для примера настроек используется только `.env.example`.
